# SIPROC
Sistema desarrollado para registrar, administrar y visualizar operaciones relacionadas al consumo y abastecimiento de combustible en flotas de transporte de carga pesada. 
Permite un control eficiente del stock, descargas de combustible y consumo proyectado.


## CARACTERÍSTICAS PRINCIPALES:
- Registro de operaciones por unidad, ruta y galonaje.
- Control del stock inicial y descargas de combustible programadas.
- Reportes detallados por operación y proveedor.
- Exportación de reportes a archivos de texto y Excel.
- Cálculo de diesel requerido y disponible.
- Ventana de resumen por ruta/destino.
## REQUISITOS:
-Java Runtime Environment (JRE) 8 o superior.
-Recomendado: JDK 17.
- Sistema operativo:
- Windows 7, 8, 10, 11.
- macOS.
- Linux.
## Editor o IDE opcional para visualizar el código fuente:
- Eclipse.
- IntelliJ IDEA.
- NetBeans.
